`dev`, `dev:build`, `dev:add` ve `dev:typecheck` dışında, `yarn beeax` CLI, fonksiyonları çalıştırma, günlükleri görüntüleme ve uygulama kurulumlarını yönetme komutları sağlar.

## Fonksiyonları çalıştırma (`yarn beeax dev:function:exec`)

Bir mantık fonksiyonunu HTTP, cron veya veritabanı olayıyla tetiklemeden manuel olarak çalıştırın:

```bash filename="Terminal"
# Execute by function name
yarn beeax dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn beeax dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn beeax dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn beeax dev:function:exec --postInstall
```

## Fonksiyon günlüklerini görüntüleme (`yarn beeax dev:function:logs`)

Uygulamanızın mantık fonksiyonlarının yürütme günlüklerini akış olarak alın:

```bash filename="Terminal"
# Stream all function logs
yarn beeax dev:function:logs

# Filter by function name
yarn beeax dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn beeax dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Bu, Docker konteyner günlüklerini gösteren `yarn beeax docker:logs` komutundan farklıdır. `yarn beeax dev:function:logs`, uygulamanızın fonksiyon yürütme günlüklerini BeeAX sunucusundan gösterir.
</Note>

## Tiplendirilmiş istemciyi oluşturma (`yarn beeax dev:generate-client`)

Bir uygulamayı oluşturup eşitlemeden, etkin uzak sunucunun şemasından tiplendirilmiş API istemcisini (`beeax-client-sdk`) yeniden oluşturun. Bunu, BeeAX örneğinizle iletişim kuran — örneğin ayrı bir depoda bulunan bir arka uç hizmeti — herhangi bir projede tiplendirilmiş bir istemci edinmek için kullanın:

```bash filename="Terminal"
# In your project (no BeeAX app definition required)
yarn add beeax-sdk beeax-client-sdk

# Connect to the BeeAX instance to generate the client from
yarn beeax remote:add

# Generate the typed client into node_modules/beeax-client-sdk
yarn beeax dev:generate-client
```

Ardından istemciyi kodunuza içe aktarın:

```typescript
import { CoreApiClient } from 'beeax-client-sdk/core';
```

Oluşturulan türleri yenilemek için veri modeliniz her değiştiğinde komutu yeniden çalıştırın.

<Note>
İstemci `node_modules` içinde oluşturulur, bu nedenle kodunuzla birlikte commit edilmez. Her kurulumdan sonra (örneğin bir `postinstall` betiğinde veya CI içinde) `yarn beeax dev:generate-client` komutunu çalıştırın.
</Note>

## Bir uygulamayı kaldırma (`yarn beeax app:uninstall`)

Uygulamanızı etkin çalışma alanından kaldırın:

```bash filename="Terminal"
yarn beeax app:uninstall

# Skip the confirmation prompt
yarn beeax app:uninstall --yes
```

## Uzakları yönetme

Bir **uzak**, uygulamanızın bağlandığı BeeAX sunucusudur. Kurulum sırasında iskelet oluşturucu sizin için otomatik olarak bir tane oluşturur. Dilediğiniz zaman daha fazla uzak ekleyebilir veya aralarında geçiş yapabilirsiniz.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn beeax remote:add

# Connect to a local BeeAX server (auto-detects port 2020 or 3000)
yarn beeax remote:add --local

# Add a remote non-interactively (useful for CI)
yarn beeax remote:add --url https://your-beeax-server.com --api-key $TWENTY_API_KEY --as my-remote

# List all configured remotes
yarn beeax remote:list

# Set the active remote
yarn beeax remote:use <name>
```

Kimlik bilgileriniz `~/.beeax/config.json` içinde saklanır.
