Помимо `dev`, `dev:build`, `dev:add` и `dev:typecheck`, CLI `yarn beeax` предоставляет команды для выполнения функций, просмотра логов и управления установками приложений.

## Выполнение функций (`yarn beeax dev:function:exec`)

Запустите логическую функцию вручную, не вызывая её через HTTP, cron или событие базы данных:

```bash filename="Terminal"
# Execute by function name
yarn beeax dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn beeax dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn beeax dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn beeax dev:function:exec --postInstall
```

## Просмотр логов функций (`yarn beeax dev:function:logs`)

Потоковая передача журналов выполнения логических функций вашего приложения:

```bash filename="Terminal"
# Stream all function logs
yarn beeax dev:function:logs

# Filter by function name
yarn beeax dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn beeax dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Это отличается от `yarn beeax docker:logs`, который показывает логи контейнера Docker. `yarn beeax dev:function:logs` показывает журналы выполнения функций вашего приложения с сервера BeeAX.
</Note>

## Генерация типизированного клиента (`yarn beeax dev:generate-client`)

Повторно сгенерируйте типизированный API‑клиент (`beeax-client-sdk`) из схемы активного удалённого экземпляра, не выполняя сборку или синхронизацию приложения. Используйте это, чтобы получить типизированного клиента в любом проекте — например, в backend‑сервисе в отдельном репозитории — который взаимодействует с вашим экземпляром BeeAX:

```bash filename="Terminal"
# In your project (no BeeAX app definition required)
yarn add beeax-sdk beeax-client-sdk

# Connect to the BeeAX instance to generate the client from
yarn beeax remote:add

# Generate the typed client into node_modules/beeax-client-sdk
yarn beeax dev:generate-client
```

Затем импортируйте клиента в свой код:

```typescript
import { CoreApiClient } from 'beeax-client-sdk/core';
```

Повторно запустите команду при каждом изменении вашей модели данных, чтобы обновить сгенерированные типы.

<Note>
Клиент генерируется внутри `node_modules`, поэтому он не добавляется в ваш репозиторий вместе с кодом. Запускайте `yarn beeax dev:generate-client` после каждой установки (например, в скрипте `postinstall` или в CI).
</Note>

## Удаление приложения (`yarn beeax app:uninstall`)

Удалите свое приложение из активного рабочего пространства:

```bash filename="Terminal"
yarn beeax app:uninstall

# Skip the confirmation prompt
yarn beeax app:uninstall --yes
```

## Управление удалёнными серверами

**Remote** — это сервер BeeAX, к которому подключается ваше приложение. Во время настройки скаффолдер автоматически создаст его для вас. Вы можете в любой момент добавлять новые удалённые серверы или переключаться между ними.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn beeax remote:add

# Connect to a local BeeAX server (auto-detects port 2020 or 3000)
yarn beeax remote:add --local

# Add a remote non-interactively (useful for CI)
yarn beeax remote:add --url https://your-beeax-server.com --api-key $TWENTY_API_KEY --as my-remote

# List all configured remotes
yarn beeax remote:list

# Set the active remote
yarn beeax remote:use <name>
```

Ваши учётные данные хранятся в `~/.beeax/config.json`.
