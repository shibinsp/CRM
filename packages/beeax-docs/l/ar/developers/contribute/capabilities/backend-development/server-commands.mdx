## الأوامر المفيدة

يجب تنفيذ هذه الأوامر من مجلد packages/beeax-server.
من أي مجلد آخر يمكنك تشغيل `npx nx {command} beeax-server` (أو `npx nx run beeax-server:{command}`).

### إعداد المرة الأولى

```
npx nx database:reset beeax-server # إعداد قاعدة البيانات مع بذور التطوير
```

### بدء الخادم

```
npx nx run beeax-server:start
```

### Lint

```
npx nx run beeax-server:lint # مرر --fix لإصلاح أخطاء التدقيق
```

### تجربة

```
npx nx run beeax-server:test:unit # تشغيل اختبارات الوحدة
npx nx run beeax-server:test:integration # تشغيل اختبارات التكامل
```

ملاحظة: يمكنك تشغيل `npx nx run beeax-server:test:integration:with-db-reset` في حالة احتياجك لإعادة تعيين قاعدة البيانات قبل تشغيل اختبارات التكامل.

### إعادة تعيين قاعدة البيانات

إذا أردت إعادة تعيين قاعدة البيانات وزرع بعض البيانات فيها، يمكنك تشغيل الأمر التالي:

```bash
npx nx run beeax-server:database:reset
```

### عمليات الترحيل

#### للكائنات داخل مخططات Core/Metadata (TypeORM)

```bash
npx nx run beeax-server:database:migrate:generate
```

## "التقنية المستخدمة"

تستخدم BeeAX بشكل أساسي NestJS للواجهة الخلفية.

Prisma كان أول ORM استخدمناه. ولكن للسماح للمستخدمين بإنشاء الحقول والعناصر المخصصة، كان من المنطقي استخدام مستوى أقل حيث نحتاج إلى تحكم دقيق. الآن يستخدم المشروع TypeORM.

إليك شكل العناصر التقنية الآن.

* [NestJS](https://nestjs.com/)
* [TypeORM](https://typeorm.io/)
