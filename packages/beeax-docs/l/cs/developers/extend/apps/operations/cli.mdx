Kromě `dev`, `dev:build`, `dev:add` a `dev:typecheck` poskytuje `yarn beeax` CLI příkazy pro spouštění funkcí, zobrazení logů a správu instalací aplikací.

## Spouštění funkcí (`yarn beeax dev:function:exec`)

Spusťte logickou funkci ručně bez vyvolání přes HTTP, cron nebo databázovou událost:

```bash filename="Terminal"
# Execute by function name
yarn beeax dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn beeax dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn beeax dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn beeax dev:function:exec --postInstall
```

## Zobrazení logů funkcí (`yarn beeax dev:function:logs`)

Streamujte výstupní logy běhu logických funkcí vaší aplikace:

```bash filename="Terminal"
# Stream all function logs
yarn beeax dev:function:logs

# Filter by function name
yarn beeax dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn beeax dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
To se liší od `yarn beeax docker:logs`, který zobrazuje logy kontejneru Docker. `yarn beeax dev:function:logs` zobrazuje logy běhu funkcí vaší aplikace ze serveru BeeAX.
</Note>

## Generování typovaného klienta (`yarn beeax dev:generate-client`)

Znovu vygenerujte typovaného klienta API (`beeax-client-sdk`) ze schématu aktivního vzdáleného serveru, bez sestavování nebo synchronizace aplikace. Použijte jej k získání typovaného klienta v libovolném projektu – například backendové služby v samostatném repozitáři – který komunikuje s vaší instancí BeeAX:

```bash filename="Terminal"
# In your project (no BeeAX app definition required)
yarn add beeax-sdk beeax-client-sdk

# Connect to the BeeAX instance to generate the client from
yarn beeax remote:add

# Generate the typed client into node_modules/beeax-client-sdk
yarn beeax dev:generate-client
```

Poté klienta importujte ve svém kódu:

```typescript
import { CoreApiClient } from 'beeax-client-sdk/core';
```

Spusťte příkaz znovu pokaždé, když se změní váš datový model, abyste aktualizovali vygenerované typy.

<Note>
Klient je vygenerován uvnitř `node_modules`, takže není verzován spolu s vaším kódem. Spusťte `yarn beeax dev:generate-client` po každé instalaci (například ve skriptu `postinstall` nebo v CI).
</Note>

## Odinstalace aplikace (`yarn beeax app:uninstall`)

Odeberte svou aplikaci z aktivního pracovního prostoru:

```bash filename="Terminal"
yarn beeax app:uninstall

# Skip the confirmation prompt
yarn beeax app:uninstall --yes
```

## Správa vzdálených serverů

**Remote** je server BeeAX, ke kterému se vaše aplikace připojuje. Během nastavení jej generátor kostry automaticky vytvoří. Můžete kdykoli přidat další vzdálené servery nebo mezi nimi přepínat.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn beeax remote:add

# Connect to a local BeeAX server (auto-detects port 2020 or 3000)
yarn beeax remote:add --local

# Add a remote non-interactively (useful for CI)
yarn beeax remote:add --url https://your-beeax-server.com --api-key $TWENTY_API_KEY --as my-remote

# List all configured remotes
yarn beeax remote:list

# Set the active remote
yarn beeax remote:use <name>
```

Vaše přihlašovací údaje jsou uloženy v `~/.beeax/config.json`.
