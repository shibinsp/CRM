This is a [BeeAX](https://beeax.com) application bootstrapped with [`create-beeax-app`](https://www.npmjs.com/package/create-beeax-app).

## Getting Started

This app was scaffolded with a local BeeAX server running at [http://localhost:2020](http://localhost:2020).

Login with the default development credentials: `tim@apple.dev` / `tim@apple.dev`.

Run `yarn beeax help` to list all available commands.

## Useful Commands

- `yarn beeax dev` - Start the development server and sync your app
- `yarn beeax docker:status` - Check the local BeeAX server status
- `yarn beeax docker:start` - Start the local BeeAX server
- `yarn lint` - Lint the project with oxlint
- `yarn typecheck` - Type-check the project
- `yarn test:unit` - Run unit tests
- `yarn test` - Run integration tests
